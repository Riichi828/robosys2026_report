# code

標準入力から受け取った数値データの基本統計量を計算し、標準出力に表示するコマンドラインツールです。

## 機能・出力項目

入力された数値群に対して、以下の統計量を算出します。

 項目 | 説明 | 備考 |
 **データ数** | 入力された数値の総数 | 整数で出力 

 **合計値** | 全データの総和 | 浮動小数点数（`float`）で出力 

 **平均値** | データの算術平均 | 浮動小数点数（`float`）で出力 

 **中央値** | データを昇順に並べた際の中央の値 | データ数が偶数の場合は中央2値の平均 

 **最小値** | データ内の最小の数値 | 浮動小数点数（`float`）で出力 

 **最大値** | データ内の最大の数値 | 浮動小数点数（`float`）で出力 

 **標準偏差** | 標本標準偏差（不偏標準偏差） | **データ数が2つ以上の場合のみ**出力 

## 動作環境

* Python 3.x
  * 標準ライブラリ（`sys`, `statistics`）のみを使用しているため、追加パッケージのインストールは不要です。
* Linux / Unix系 OS（Ubuntu 等）
